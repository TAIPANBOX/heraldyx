# heraldyx 0.2.4

Keep the operator informed after the hourly mail ceiling is reached.

## What changed

- **A bounded suppression summary** (#72): while alerts are held, send a
  summary every ten minutes, or sooner for a burst of fifty, with the count,
  start time and worst severity. A one-minute floor prevents a burst of
  summaries.
- **Critical alerts pass the ceiling** (#72): they still pass through dedup,
  and the process logs what the ceiling holds and when the next summary will
  leave.
- **The decision diagram matches that behavior** (#74): its ceiling cell
  describes the summary cadence and critical bypass.
- **A bounded file watcher** (#69): each poll caps bytes read from a plane's
  burst so the notifier does not exhaust memory while catching up.
- **Shared contract dependency** (#70): updates agent-stack-go to v1.0.1.

## Evidence and limit

The regression input came from the 2026-09-17 appliance run with v0.2.3.
`VALIDATION.md` records the broken binary's silence, the fixed binary's
output, red-first tests and nine product mutations caught by the tests.
SMTP delivery after this change has not been measured on the appliance;
the fixed end-to-end run used file delivery.
