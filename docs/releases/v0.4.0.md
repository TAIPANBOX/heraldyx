# heraldyx 0.4.0

The mail now describes the on-box chain verifier's findings and TokenFuse's
retained calls and their closures, instead of the generic "does not have a
description" wording.

## What changed

- **TokenFuse's `call_retained` and `retained_closed` are described** (#95,
  invariant 24, D10). A retained call mails as "run Y made a call that was
  sent and never answered, and $Z stays reserved until a person closes it",
  with the reservation and the model, whether a restart keeps it (from
  `journaled`) and, when `listed` is false, that it cannot be closed from the
  console. A closure mails as "run Y had retained reservation N closed by a
  person as observed (or no charge), settling $Z", and says that who closed it
  is in the console's own record of the command, `console.close_retained`.
  - **The evidence reference is never mailed.** `@decided 2026-10-12`: the mail
    shows only the three numeric keys, `reservation_id`, `amount_microusd` and
    `settled_microusd`. `evidence_ref` is free text typed in the console and,
    since a model may propose a closure with its evidence, could be text a
    model wrote that a person accepted; the mail says the reference is in the
    console. The three keys are added to the `data` allowlist and kept out of
    the generic fact line.
- **agent-conform's `chain_broken` and `chain_unchained` are described** (#89).
  A break names the stream file, the first broken line, how many breaks the
  file holds and the kind, says what a break is evidence of (the stream was
  edited or two writers interleaved; the verifier does not say which or who)
  and where to look. An unchained stream says it is not a break and what it
  costs. The verifier's clipped hashes are never printed.
- The catalog holds 50 types (46 in 0.3.0).
- **Dependencies, toolchain and CI:** agent-stack-go v1.1.0 (#88), Go 1.27.2
  (#91), the estate secret scan on every pull request and push to `main`
  (#93), and the teeth harness checks a needle with a here-string, because
  `printf | grep -q` under `pipefail` reported a present needle as missing on
  GNU grep (#95).
- **Docs:** decisions recorded as `@decided` paraphrases (#92), the README's
  package count, image name and registered sources (#90).

## Upgrading

- **Nothing to configure.** No variable was added or removed. The two new
  TokenFuse types appear only once a TokenFuse that writes them (1.10.0 or
  later) exports events.

## Not proven

- No event written by a running TokenFuse or a running `agent-conform` was
  mailed through SMTP; the wording was measured by rendering events through
  the binary with file delivery.
- Two `call_retained` or two `retained_closed` events on one run inside the
  dedup window produce one mail, because the dedup key is the type and the
  run; measured, not changed.
- A model name that is a bare host and path, with no scheme and no `www.`, is
  still printed, and some mail clients turn it into a link.
