# Heraldyx 0.8.2

A patch release on 0.8.1. The binary and the image are built with Go 1.27.3, which fixes GO-2026-6809 in `crypto/x509`. The 0.8.1 image was built with Go 1.27.2. The finding was reached through the SMTP TLS handshake in `deliver.SMTP.connect`. Nothing an operator sets or sees moves: no variable, route, mail text or file changes, and the 0.8.1 upgrade section needs nothing new.

## Changed since 0.8.1

- **Go 1.27.3 (#125).** The `toolchain` line in `go.mod`, the CI `go-version` and the `GO_VERSION` of the `Dockerfile` move to 1.27.3. staticcheck stays on go1.27.1, as before.
- **Documentation (#124).** The README states that Keyryx was released on the day it was registered, not still reserved.

No other commit lies between the 0.8.1 tag and this release.

Pull `ghcr.io/taipanbox/heraldyx:v0.8.2` and restart.
